# B-29 — ゆっくり宇宙を旅するゲーム

2041年6月1日、地球低軌道。21歳のカイトは、全財産をはたいて買った中古の宇宙船 **B-29** に一人で乗り込み、地球を出発した。
人類の宇宙電波網は月軌道まで広がり、無数の 5G 基地局が宇宙に浮かんでいる。船には独立 AI「アスファルト」と、10年間無給電で飛べる小型原子炉が積まれている。

ミッションも目的もない。窓から地球を眺め、コーヒーを淹れ、ふらふらと旅をする。
……ただし、ときどき小惑星がぶつかってくる。

## 特徴

- **一人称・スマホ横画面・全画面**。画面上の文字はほぼ無し。操作はタッチと、船内のモニターを直接タップする方式（タップすると画面いっぱいまで近づいて操作できる）。
- **原寸大の地球**（NASA Blue Marble / Black Marble / GEBCO 標高）。大気散乱・雲・夜景・稲妻。
- **本物の高精細な地表**：オンライン時は、カメラの周りに **Sentinel-2 の雲なし衛星画像（最大 約10 m/ピクセル）**と**実測の標高データ（SRTM など、最大 約20 m）**をその場で読み込む。山・谷・川・海岸線・街並みが本物の形で見え、着陸もその地形の上にできる（オフライン時は同梱の全球データで表示）。
- 宇宙船は外観まで 3D で作り込まれ（外板パネルの継ぎ目・リベット・腹の耐熱タイル・配管・アンテナ・センサー・エンジンの冷却管など）、**実際の機体として 3D 空間を移動**する（窓の外の景色は写真ではなく本物の 3D 世界）。
- 船内は外装と同じく**丸い**：アーチ天井とリブの通路、間接照明、角の丸い造り付け家具、窓から差し込む光の筋。壁は**装甲板**（面取りした深い継ぎ目・リベット列・ボルト留めの補強板）で、腰から下はダークガンメタル＋アンバーのライン。通路は太いボルト留めの鋼鉄フレームとキックプレートで重厚に、扉は**厚さ 30 cm 以上のボルト留めの枠**にはまり、上には部屋名の発光サイン。部屋には消火器・救急箱・運動用バイク・植物棚・工具箱などの小物がぎっしり。
- 機関室には大きな操作卓（スイッチ列・計器・SCRAM ボタン）と、遮蔽された丸窓から見える**原子炉の炉心**。
- **宇宙ステーション**（回転居住リング・窓明かり・点滅灯）と、赤道の海上基地から静止軌道の先まで伸びる**宇宙エレベーター「アメノミハシラ」**（昇降するクライマー付き）。エレベーターの途中（高度 420 km）には大きな**「天の御柱 低軌道ステーション」**、静止軌道には**アマテラス静止港**がある。出発直後は目の前にシラサギ・ステーションが見える。
- **宇宙エレベーター「アメノミハシラ」は 2 本のリボン**（幅 1.6 m のカーボンナノチューブ帯、8.4 m 間隔）。遠くからは太陽の照り返しが滑っていく光の糸、近くでは綾織りの繊維・25 m ごとのチタン帯・100 m ごとのマーカー・km 帯・縁のケーブル・マーカー LED・2 km ごとの赤い航空灯が見える。地球の影に入ると暗くなり、境目では夕焼け色になる。
- **クライマーは時刻表で動く**：地上線（海上基地 ⇄ 天の御柱、15 分ごと）、静止線（天の御柱 ⇄ アマテラス、1 時間ごと）、外縁線（アマテラス ⇄ カウンターウェイト、6 時間ごと）。上りは北側のリボン、下りは南側のリボン。駅を出るときはゆっくり這い出して加速し、着くときは減速してゆっくり入ってくる。2 階建ての旅客クライマー（パノラマ窓・スライドドア・放熱フィン・レーザー受電リング・ヘッドライト・ストロボ）と、コンテナを 4 つ抱えた貨物クライマーがある。
- **ターミナルのバース**：着いたクライマーをグリップで掴み、搭乗ブリッジが伸びてドアが開き、乗り降りが終わるとトラバーサーが反対側のリボンへ横移動させ、また客を乗せて出発する。回転灯・レーン表示灯・投光器、接近中は誘導灯がバースへ向かって流れる。ドッキング中はチャイムと構造越しの「ゴトン」という音、出発時の低いうなり。ナビ画面に次のクライマーの到着時刻が出る。
- 海上の**アンカー基地**（塔・給電ドーム・港・船）からは、大気の中だけ見えるレーザー給電ビームが上っていくクライマーへ伸びる。上端は小惑星をおもりにした**カウンターウェイト・ステーション**。リボンに何か当たると火花と破片が飛び、波がリボンを伝わる。切れたリボンは端が大きくのたうちながら離れていく。
- ステーションには**ドッキングして中を歩ける**：大理石の床・金の窓枠・ラウンジ・バー・植物・地球を見下ろすガラス床のある豪華なロビー。ステーションには当たり判定があり、ぶつかると船が壊れる。
  - 区画の間は**重い気密扉**：歯がかみ合う二枚の扉とゴムのシール、レール上のローラー。近づくと、ロックバーが跳ね上がり（ガチャン）、扉がシールから浮いて「プシュッ」と蒸気を吹き、両側の壁へ滑り込む。動いている間は枠のライトが流れ、上の回転灯が回る。横の画面に両側の区画の気圧と扉の状態が出る。片側の気圧が下がると非常閉鎖で叩きつけるように閉まってロックされ、赤く点滅して開かない。
- **小惑星は 3D で本当に飛んできて衝突**し、船体がへこむ・穴が開く・窓にひびが入る・配管が破れる・機器が壊れる。船内の壁も歪み、物が飛び、揺れる。
- **撃たれた所が段階的に剥がれる破壊エンジン**（B-29・H8・敵ドローン専用）：弾は一発ごとに**当たったその場所**に跡を残し、**同じ所にもう一発当たると一段階、さらにもう一発でさらに一段階**深く剥がれる。新しい層のギザギザの縁が当たった所から一瞬で広がり、剥がれた破片（塗装の薄片・丸まった外板・金色の断熱材の切れ端・構造の破片・セラミックの欠片）が**物理法則どおりに**（船の軌道運動＋被弾の勢いで、回転しながら）飛んでいき、**光の尾を引く火花**が散る。
  - **B-29（3段階）**：①塗装が吹き飛んで熱で変色したアルミ地肌 → ②外板が裂けて**金色の断熱ブランケット**が露出 → ③**貫通**：断熱材が焼け落ち、フレームとストリンガー・切れたケーブル・奥の与圧殻まで見え、縁は赤熱して30秒ほどかけて冷え、周りの外板は**花びら状に引き裂かれて外へめくれる**。裂けた外板の上に付いていた機器（箱・ボンベ・センサーなど）は**一緒にもぎ取られて飛んでいく**（大きな衝撃でパネルがはがれたときも同じ）。腹ではタイルの釉薬 → **タイルが1枚ずつ丸ごと**欠け → 外板。貫通した所にさらに当たると**船内まで穴が開いて空気が漏れる**。
  - **H8（5段階・装甲が硬い）**：①表面コーティングが焼けて装甲鋼が露出 → ②セラミック層が割れて欠ける（放射状・同心円のひび）→ ③セラミックが砕けて織物の裏打ち層 → ④裏打ちが裂けて**チタンのハニカム** → ⑤**内壁まで貫通**：裂けた装甲の花びら、切れた配線の火花、赤熱。
  - **敵ドローン（3段階）**：塗装 → 装甲板 → 中身（基板・配線）が見えて赤く光る。当たった位置は外側の球ではなく**本当の機体の表面**。
  - 穴の中は視線を奥へたどって描くので、角度を変えると層の段差と深さがちゃんと見える。周りには**すすが不規則に広がり**、縁の塗装が欠ける。描かれた文字や弾痕は、その下の層ごと消える。セーブされ、修理基地で直る。
- **大きな衝撃（岩など）で船体が壊れる**：外板パネル（1.2×0.6 m、千鳥配置）は大きな打撃で**留め具が外れて半分めくれ**、さらに**ちぎれて宇宙へ飛んでいく**。大きな一撃はパネルに**穴を引き裂き**、はがれた所からは中の構造が奥行きをもって見える。腹の**耐熱タイル**が欠けたまま大気圏に突入すると**そこから熱が入って焼け抜ける**。
- 自分で直せるのは**ごく軽微な損傷だけ**。それ以外は放っておくと**どんどん悪化**し（ひびが広がって窓が割れる、漏れが増える、金属疲労で新しい損傷が生まれる）、船体強度が尽きると**船がバラバラに砕け散る**。大きな損傷は約10日かかる修理基地（ツクヨミ・ドック）でしか直らない。
- 船・ステーションが危険な状態になると**赤い非常灯が点灯し、警報がしばらく鳴る**（危険度に応じて船内照明も赤く染まる）。
- **ステーションと宇宙エレベーターにも小惑星が当たる**：焦げ跡・穴・空気の噴出・火災、照明のちらつき、居住リングの停止、クライマーの停止。大きく当たると崩壊して残骸だけになる（エレベーターはケーブルが切れる）。これはプレイヤーには直せない（生きている所はステーションの作業員が少しずつ直す）。ナビ画面に各施設の状態が出る。
  - **緊急事態の演出**：穴からは空気と氷の粒が**噴流になって噴き出し**（区画の空気が抜けるにつれて弱まる）、火災の穴からは火の粉が漂い、千切れたケーブルが**放電**する。危険な状態のステーションでは**二次爆発**（閃光・火球・衝撃波・煙・破片）が起きて状態がさらに悪化し、**赤い回転非常灯**が点き、乗員が**脱出ポッド**で避難する（噴射しながら離れていく）。ドッキング中ならロビーの照明が落ちて赤い非常灯と警報音に変わり、爆発で区画に穴が開くこともある。
  - **本当に危ない**：残骸や燃えているステーションのまわりには**破片が飛び交い、近づくと B-29 に当たる**（自動操縦は残骸から十分離れた位置で止まる）。
- 区画ごとの気圧・酸素・二酸化炭素のシミュレーション。空気が漏れれば本当に減圧し、隔壁を閉じて閉じこもる必要もある。
- 床下の**配管層**は入り組んだ迷路。水再生装置・藻類バイオリアクター・姿勢制御ホイール・バッテリー群などが並ぶ。損傷箇所まで実際に行かないと修理できない。バルブで系統を遮断できる。
- 昇降機（リードスクリュー駆動）、コーヒーメーカー（グラインダー・ヒーター・ピストン）、シャワー、原子炉とタービン、サーバー、ファン、O2 生成装置、エアロックなど、**機械は内部機構ごと動作**する。
- **船外活動**：宇宙服を着て、エアロックを減圧し、ハッチから外へ。手すり・はしごあり。自由に船体の周りを飛べる。
- **大気圏突入**（加熱・プラズマ・振動）と**着陸・着水**（速度次第で損傷・破壊）。地球の重力下では船内にも重力がかかり、外を歩ける。
- **B-29 のコックピットは大画面の曲面タッチディスプレイ**：机・モニター・キャノピーのガラスはすべて撤去。操縦席の前に、足元近くから頭上まで・左右 160 度を包む**1枚の大きな曲面ディスプレイ**が暗い隔壁にはめ込まれている（H8 のように 360 度ではない）。機首のカメラの映像を**パイロットの目の位置から合成**して映すので、ディスプレイの向こうは**機首が無いかのように**外が見える（頭を動かせば視差もそのまま）。船の情報はディスプレイ自身の画素として描かれた**3枚のパネル**（左：船体・系統／生命維持／通信、中央：航法／状況、右：カメラ）にまとまり、上のタブで切り替えて、触れた所がそのまま押せる。機首に被弾すると画面がその方向から赤く裂け、ひどいと黒く死に、電源やカメラが落ちると暗いガラスになる。外から見ると、キャノピーのあった所は**暗い装甲ガラスのセンサー帯**で、カメラのレンズが並んでいる。ULTRA スイッチと警報の消音ボタンは**肘掛けの横のポッド**に移った。
- **機械の音は一つのメーカーで統一**：扉・ハッチ・ドッキングのクランプ・ラッチ・バルブ・昇降機（ブレーキと柵のサーボ）・アンビリカルケーブル・H8 のラジエーター翼・ガンリングの砲塔台車（速さに応じてうなりが上がる）・ミサイル発射筒の扉と装填機・シャワーの扉・宇宙エレベーターのグリップと搭乗ブリッジ・宇宙服のラック——ロックが外れる「カチッ」とガスの抜ける音、電動ドライブの立ち上がり、終点の重い「ドン」と金属音、閉まるときのシールの「シュー」まで、同じ音の作りで鳴る。
- **ULTRA**：最大秒速 900 m（従来の3倍）。点火時の衝撃や航行中の振動で、場合によっては船体が揺れたり壊れたりする（大気中や船体が弱っているほど危ない）。船体強度が60%を切るとアスファルトが安全のため ULTRA を止める（自己責任で再点火はできる）。解除すると段階的に元の速度へ戻る。ULTRA 中でも自動操縦が使える。慣性ダンパー付き。
- **自動操縦**はすべての目的地に到着できる（低軌道のステーション・宇宙エレベーターの途中駅・静止軌道・月軌道の修理基地まで）。
- **セーブしても世界は止まらない**：アプリを閉じていた時間も軌道上の移動・自動航行・損傷の悪化・衝突が進む（最大30日分）。
- 警報は派手（回転灯・赤い非常灯・画面の赤い脈動・サイレン）で、消音ボタンで止められる。
- **H8（エイチエイト）— カイトの昔のサブ拠点**：直径 7.2 m の球形の小型ステーション。この船より**外部装甲・内部装甲ともに倍以上分厚く**、面取りした装甲板（一枚ずつ色の違う板・交換された板・オレンジの赤道帯）を数千本のボルトで留め、外には専用カメラ4台・プラズマドライブ（磁気ノズル・超電導コイル・冷却管）・補助エンジン4基・RCS 8基・ラジエーター翼・レーダードーム・スタートラッカー・高利得アンテナ・レーザー端末・ドッキングネックと両性型ドッキングリング・高速給電カプラーがある。中は機械と配線がぎっしりで、真ん中のコックピットは**人ひとりがぎりぎり**。窓はなく、**4台のカメラ映像をリアルタイム合成した360度ディスプレイ**で外が見える。新しいゲームでは **B-29 の真上（60 m）** に浮かんで待機している。
  - **360度ディスプレイ**：水平線とピッチ目盛りはディスプレイ自身がくっきり描き（ちらつかない）、目印は**カイトの目から見た方向**に正確に重なる。情報は**2枚のタブ**（操縦：航法・推進/電力・兵装・カメラ／機体：機体・B-29・HACHI・装備）にまとまっていて、**ディスプレイ自身の画素として球面のガラスに描かれる**（座席や手が手前に重なり、パネルの継ぎ目や故障もタブの上に出る）。文字は大きく明るく、周りの明るさに合わせて見やすい明るさに保たれる。タブはドラッグで移動、ピンチで拡大縮小。**見つめた目標を自動でロックオン**（最大8つ同時、衝突コースの岩は自動ロック）し、名前・距離・接近速度・衝突までの秒数を表示する。
  - **外部カメラのズーム**：光学 100 倍＋ AI 処理のデジタルズーム（最大 1000 倍）。拡大されるのはディスプレイに映るカメラ映像だけで、コックピットやタブは拡大されない。
  - **壊れ方がリアルなディスプレイ**：被弾の衝撃でパネルが傷むと、ドライバーの故障による縦線・横線（色が固まる／消える）、液晶のにじみ（黒いしみと虹色の縁）、ちらつくバックライトと縁からの光漏れが出て、ひどいとカバーガラスが**放射状と同心円状にひび割れ**（頭を動かすとひびが光る）。カメラが傷むとその方向の映像がブロック状に崩れ、カメラが死ぬとブラウン管のように線→点になって消える。
  - **緊急シェルター**：肘掛けの前端の**赤いボタン**（透明カバー付き：1回目でカバーが上がり、2回目で作動）を押すと、座席の下の床ディスプレイが左右にスライドしてレールがせり上がり、伸びて後部まで届く。座席はカイトごと**勢いよく後ろへ撃ち出され**、座席一つがやっと入るシェルターに収まって密閉される（独立酸素 10 時間・CO2 吸収・電池・コンソール・カメラ画面）。その後レールは床に戻り、床が閉じてコックピットは空になる。シェルターの右の壁のシャッターの中に**宇宙服**がある。もう一度ボタン（または退出ボタン）でコックピットに戻る。H8 が破壊されてもシェルターだけは残って漂流し、救助を待てる。
  - **回転する操縦席**：座席が支柱ごと360度回り、後ろを振り向くと体ごと座席が向きを変える（操縦桿とスロットルも座席と一緒に回る）。
  - **戦闘**：船体を一周する**2本のガンリング**の上を砲塔が走り、H8 が向きを変えなくても全方位に撃てる（上下は上下のリングで分担）。**ミサイル**は発射筒2基・射程 120 km・再装填 1 秒。弾とミサイルは**小型原子炉の電力で船内生産**され、敵が 50 km 圏内にいて弾が足りないと HACHI が判断すると、**ローエンジンモード**に切り替えて生産に電力を回す。自動迎撃を ON にすると HACHI が最寄りの敵を撃つ。敵ドローンは **★1〜★5** の強さがあり、ミサイルを最大の脅威として回避しつつ撃ち落とそうとする。
  - **本当にへこむ装甲**：被弾すると装甲板・ボルト・マーキングごと**実際にへこみ**、さらに上の破壊エンジンで**5段階**に剥がれていく。大きな一撃は装甲板を**ボルトごと丸ごと外して**飛ばし（下の暗い層が見える）、内側の装甲まで抜かれると**船内の空気が氷の粒になって噴き出す**。カメラの近くに当たるとそのカメラが壊れ、360度ディスプレイのその方向が映らなくなる。船内では照明がちらつき、操作盤から火花が散る。
  - H8 の AI「**HACHI**」は無口で頭の切れる自動操縦。地球を回り込む誘導・停泊軌道からの呼び出し・岩塊や他のステーションの回避・動いている B-29 への**精密自動ドッキング**までこなす。小さな岩は**レーザーで撃ち落とし**、大きな岩は回避機動をとる。
  - **B-29 の背中（上部ドッキングポート）に結合**できる。結合中は H8 が推進を担い、**内部原子炉だけで6倍、B-29 からの高速給電（アンビリカルケーブル）を受けると12倍**の速度が出る（ULTRA 時は最大 約 10.8 km/s）。B-29 のエンジンが壊れていても H8 の推力で飛べる。
  - 通路の天井の上部ポートから H8 に上がれる（ハッチは壁のパネルで開閉）。H8 の操縦席に座れば、そのまま結合した船を操縦できる。**分離して H8 だけで飛ぶ**こともできる（手動操縦・HACHI の自律航行・帰還ドッキング）。

## 遊び方

| 操作 | やり方 |
|---|---|
| 移動 | 画面の左側をドラッグ（仮想スティック） |
| 視点 | 画面の右側をドラッグ |
| 触る | 物を直接タップ（扉・座席・機械・バルブ・損傷箇所など） |
| モニター | タップすると近づく → ボタンをタップ。戻るときはモニターの外か左上のボタン |
| 上昇／下降 | 右端の ↑↓ ボタン（無重力のとき、はしご・手すりにつかまっているとき） |
| 立つ／戻る | 左上の退出ボタン |

### 操縦
- コックピットの操縦席をタップして座る。
- **左スティック**：上下＝速度（スロットル）、左右＝ヨー。**右スティック**：上下＝ピッチ、左右＝ロール。
- 左上のカメラボタンで**船外カメラ**。船外カメラを見ながらでもスティックで操縦できる。▶でカメラ切替。
- 船外カメラは**画面の中央〜上側をドラッグすると自由に動かせる**（後方カメラは船の周りをぐるっと回り込み、取り付けカメラは上下左右を見回す）。2本指のピンチ（PCはマウスホイール）で寄る・離れる、ダブルタップで元に戻る。
- **ULTRA**：右の肘掛けの横のポッドにある赤いカバー付きスイッチ、またはナビパネルの ULTRA ボタン。
- **自動操縦**：ナビモニターで目的地をタップ →「自動操縦 開始」。修理基地に着いたら「ドッキング・修理」（H8 が結合していれば H8 の装甲も直る）。

### ステーションに寄る
1. ナビモニターで行き先のステーション（シラサギ、天の御柱など）を選び、自動操縦で近づく。
2. 近く（約 2 km 以内）まで来たら、ナビモニターの「**ドッキング**」をタップ。船がぐるっと回り込み、エアロック側から自動で接岸する（もう一度タップで中止）。
3. ドッキングしたら、エアロックの**外側ハッチ**を開ける（減圧は不要）。通路を抜けるとロビー。
4. 帰るときは船に戻って外側ハッチを閉め、ナビモニターの「**離脱（アンドック）**」。
- 天の御柱は軌道を回らず地球と一緒に回っているので、ドッキング中は船内にもロビーにも約 0.9G の重力がかかる。

### H8 を呼ぶ・乗る
1. ナビモニター左上の「**H8 を呼ぶ**」をタップ。真上で待機している H8 が起動し、HACHI が降りてきて B-29 の背中にドッキングする（H8 を遠くへ行かせたときは、ナビの目的地「H8（サブ拠点）」を選んで自動操縦でこちらから迎えに行ってもいい）。
2. 結合したら、通路の天井（倉庫の扉の手前）にある**上部ポート**の下、壁の**青いボタン**をタップしてハッチを開ける。上に浮かんでいけば H8 のシャフト、その先がコックピット。
3. 操縦席をタップして座ると、B-29 と H8 をまとめて操縦できる（推力 6〜12 倍）。H8 の3枚のモニターは上の**タブ**でページを切り替えられ、結合中は **B-29 の航法・自動操縦・ULTRA・システム・扉・生命維持・原子炉・通信** もそのまま操作できる。
4. H8 のナビ画面「**B-29 から分離（単独飛行）**」で、カイトを乗せたまま H8 だけで飛べる。帰るときは「**B-29 へ帰還・ドッキング**」、B-29 にこちらへ来てもらうときは「**B-29 を呼ぶ（ここへ）**」。乗っていないときに分離すると、HACHI が上で護衛するか停泊軌道へ帰る。降りるときは「戻る」ボタン（座席の後ろの床ハッチの上に立つ）。
5. **通信リンク**：H8 と B-29 は **1500 km 以内**なら無線でつながり、お互いの状態（推進剤・船体・電力・警報・航行状態）を見たり、**呼び出し合ったり**できる（H8 の「B-29 リンク」タブ、B-29 の通信モニターの「H8 リンク」）。それより離れると圏外で呼べない。
6. **推進剤（燃料）**：B-29 も H8 も推力を出すと推進剤を使う（呼び出しで飛んでくるときも、来る側の推進剤を使う。足りないと呼べない）。B-29 はステーションにドッキングすると補給され、修理基地では満タンになる。結合中の H8 は給電ケーブルと一緒に B-29 から推進剤をもらい、逆に「推進剤を B-29 へ送る」こともできる。空になると予備スラスターでゆっくりしか動けない。

### 暮らし
- **コーヒー**：リビングのコーヒーメーカーをタップ。できあがったらもう一度タップして受け取り、画面右下をタップで飲む。無重力ではパウチに入る。
- **シャワー**：バスルームのシャワーをタップ（水は循環するが少しずつ減る）。
- **眠る**：リビングのモニター →「眠る（時間経過）」。寝ている間は時間が早く進む（警報中は眠れない）。
- **ラジオ**：5G の電波が届いていれば音楽が聴ける。

### 損傷と修理
1. 衝突するとアスファルトが音声でだいたいの場所を教えてくれる（システムモニターにもおおまかな位置が出る）。
2. 倉庫の**赤い修理キット**をタップして持つ。
3. 損傷箇所まで**実際に行って**、壊れている所をタップすると作業が始まる。
4. 小さな穴・ひび・小さな配管漏れ・軽い故障は応急処置できる。大きな損傷はツクヨミ・ドック（約10日）まで行かないと直らない。
5. 配管層へは、通路の昇降機（柵の黄色いボタン）か機関室の床中央のハッチ（はしご）から降りる。漏れている系統はバルブを閉めて止められる。
6. 減圧した区画は、穴を塞いでから生命維持モニターの「再加圧」で空気を戻せる。

### 宇宙服と船外活動
- **宇宙服は2着**：B-29 のエアロックのラックに **B-29 CS-2**（中級・民間用：ブースター1基、最大秒速 100 m、飛行 30 分、酸素 8 時間、充電 30 分）、H8 のシェルターの壁の中に **H8 EVA-X**（最高グレード：ブースター2基、最大秒速 500 m、飛行 1 時間、予備バッテリー1個、酸素 24 時間＋非常用 30 分、防弾・高耐久のバイザー、充電 10 分）。それぞれの宇宙服がバッテリー・酸素・傷の状態を持ち、ラックにある間は自分の船の電力で充電され、酸素も補充される。
- **宇宙服のつくり**：硬い上半身（胸の表示・操作モジュール、肩と腰のベアリング、パックからのホース、名札・グレードのバッジ・国旗）、関節で蛇腹に折れる布の腕と脚（側面の拘束ケーブル、色付きロックのベアリング）、指の関節まである手袋、ラグ付きのブーツ、ヘルメット（防護バイザーの縁取り、こめかみのライト、カメラ、上のライトバー、金のサンバイザー、ガラスの反射）。H8 の宇宙服はグラファイトとオレンジで、腿・すね・前腕に装甲板と左右のブースターポッド。中の顔はバイザー表示の光でうっすら照らされ、角度を変えると見える。
- **着るとき**：B-29 ではラックの宇宙服をタップ。ターンテーブルが宇宙服をくるりと回して背中を向け、**背中の扉（バックパック）が開いて**シール枠と暗いパッド張りの内側が見え、カイトは**ハッチから中へもぐり込み**（宇宙服の中で一瞬暗くなる）、頭がヘルメットに収まると**視界の縁にヘルメットの内側**が見える。扉が閉まってシールされ、バイザーの表示が起動し、ターンテーブルが部屋の方へ向き直って、一歩前へ降りる。H8 ではシェルターの座席から壁の宇宙服をタップ：シャッターが上がり、台車が宇宙服を座席の前まで運び出して回し、同じように後ろから入って座席に戻る。脱ぐときは逆の順番（気圧がある所でだけ）。
- **バイザーの専用表示**（ガラスの曲面に沿って映る）：酸素（主タンク・非常用・この使い方であと何時間）、バッテリー（予備・全開で飛べる残り時間・ブースターの状態）、B-29 などに対する速度、B-29・H8 の方向と距離、宇宙服の各部の状態と故障した機能、バイザーのひび。下のボタンで**ライト・サンバイザー・カメラ・救助要請・ブースター・自動停止**。
- **ヘルメットのカメラ**：24–70 mm の光学ズームと、その先 5 倍までのデジタルズーム（画素の切り出しなので粗くなる）。スライダーかボタンでズーム、丸いボタンで撮影。船内のモニターを拡大すると、**モニター自身の画素がそのまま**見える（なめらかに引き伸ばされない）。
- **飛び方**：左スティックで前後左右、↑↓で上下（見ている向きが基準）。ふだんは**微調整スラスター**（船体のそばでも安全な速さ）、「ブースター」を入れて前へ押すと本気の加速（H8 の宇宙服は 14 m/s²、B-29 の宇宙服は 4 m/s²）。何も操作しないと飛行コンピューターが止まってくれる（「自動停止」）。ブースターが片方壊れると横へ流れる。
- **ぶつかると壊れる**：ぶつかった速さ・向き・相手の硬さから、当たった部位（バイザー・ヘルメット・胴体・背中のパック・腕・脚）に傷・ひび・破損が入り、衝撃で表示・通信・カメラ・ライト・制御・ブースターが壊れることもある。破れると空気が漏れて酸素が何倍も早く減る。バッテリーか制御が死ぬと受動生命維持だけになる。B-29 の宇宙服は弱く、H8 の宇宙服はめったに傷つかない。
- **救助要請**（バイザーのボタン）：**B-29 を呼ぶ**（B-29 がそばまで来る）／**H8 を呼ぶ**（H8 が分離して飛んできて、すぐそばで待つ）／**最寄りのステーション**（救助タグが来て B-29 のエアロックまで曳航してくれる）。
- **ステーションの EVA ハッチ**：どのステーションにも、ロビーの上の外壁に**黄色い枠の EVA ハッチ**（緑のランプが点滅）がある。宇宙服で近づくとバイザーに「ハッチに入る」が出て、ステーションの中に入れる（B-29 はステーションのタグが自動で係留してくれる。遠すぎるとできない）。出るときはロビーの奥の壁の EVA ハッチから。
- **船外へ**：エアロックの内扉を閉め、エアロックのモニターで「**減圧**」→「**ハッチ 開**」。戻ったらハッチを閉め、「**加圧**」してから内扉を開ける。地上に着陸しているときは外の空気があるので、減圧せずにハッチを開けられる。宇宙服を着たまま H8 のシェルターにも入れる。

### 画質（高 / ロー）
- タイトル画面の「画質」ボタン、またはコックピットの**システムモニター**の「画質」ボタンで切り替える（この端末に記憶される）。
- **ロー**は処理を約半分にする設定：描画解像度を約 0.72 倍（画素数は約半分）、アンチエイリアスとブルームを軽く、船内のリアルタイム照明を 16 灯→8 灯、太陽の影を 1/4 サイズ・地球光の影なし、地形を粗く、ステーションを描く距離を 400 km→160 km、外部カメラ映像とモニターの更新を遅く、光の筋なし、船体表面のディテールを 1 方向投影に。ローのまま起動すると**形の分割数も約半分**になり、画面のポリゴン数が約 4 割減る（形の細かさだけは次の起動から反映）。
- 確認用の測定（同じ場面・ソフトウェア描画）では 1 フレームあたり 4.4 秒 → 2.0 秒。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173 （同じ Wi-Fi のスマホからも開ける）
npm run build    # dist/ に本番ビルド
```

- スマホではホーム画面に追加すると全画面・横向きで起動します（PWA）。
- GitHub Pages で公開する場合は、リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。以降はプッシュのたびに自動で更新されます（すぐ反映したいときは Actions タブの「Deploy to GitHub Pages」→「Run workflow」）。
- 高性能なスマホ向けに、画質・アニメーションに妥協していません（WebGL2 必須）。
