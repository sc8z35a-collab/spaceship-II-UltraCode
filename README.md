# B-29 — ゆっくり宇宙を旅するゲーム

2041年6月1日、地球低軌道。21歳のカイトは、全財産をはたいて買った中古の宇宙船 **B-29** に一人で乗り込み、地球を出発した。
人類の宇宙電波網は月軌道まで広がり、無数の 5G 基地局が宇宙に浮かんでいる。船には独立 AI「アスファルト」と、10年間無給電で飛べる小型原子炉が積まれている。

ミッションも目的もない。窓から地球を眺め、コーヒーを淹れ、ふらふらと旅をする。
……ただし、ときどき小惑星がぶつかってくる。

## 特徴

- **一人称・スマホ横画面・全画面**。画面上の文字はほぼ無し。操作はタッチと、船内のモニターを直接タップする方式（タップすると画面いっぱいまで近づいて操作できる）。
- **原寸大の地球**（NASA Blue Marble / Black Marble / GEBCO 標高）。大気散乱・雲・夜景・稲妻。
- **本物の高精細な地表**：オンライン時は、カメラの周りに **Sentinel-2 の雲なし衛星画像（最大 約10 m/ピクセル）**と**実測の標高データ（SRTM など、最大 約20 m）**をその場で読み込む。山・谷・川・海岸線・街並みが本物の形で見え、着陸もその地形の上にできる（オフライン時は同梱の全球データで表示）。
- 宇宙船は外観まで 3D で作り込まれ（外板パネルの継ぎ目・リベット・腹の耐熱タイル・配管・アンテナ・センサー・エンジンの冷却管など）、**実際の機体として 3D 空間を移動**する（窓の外の景色は写真ではなく本物の 3D 世界）。
- 船内は外装と同じく**丸い**：アーチ天井とリブの通路、間接照明、角の丸い造り付け家具、窓から差し込む光の筋。壁は**装甲板**（面取りした深い継ぎ目・リベット列・ボルト留めの補強板）で、腰から下はダークガンメタル＋アンバーのライン。通路は太いボルト留めの鋼鉄フレームとキックプレートで重厚に、扉は**厚さ 30 cm 以上のボルト留めの枠**にはまり、上には部屋名の発光サイン。部屋には消火器・救急箱・運動用バイク・植物棚・工具箱などの小物がぎっしり。
- 機関室には大きな操作卓（スイッチ列・計器・SCRAM ボタン）と、遮蔽された丸窓から見える**原子炉の炉心**。
- **宇宙ステーション**（回転居住リング・窓明かり・点滅灯）と、赤道の海上基地から静止軌道の先まで伸びる**宇宙エレベーター「アメノミハシラ」**（昇降するクライマー付き）。エレベーターの途中（高度 420 km）には大きな**「天の御柱 低軌道ステーション」**、静止軌道には**アマテラス静止港**がある。出発直後は目の前にシラサギ・ステーションが見える。
- ステーションには**ドッキングして中を歩ける**：大理石の床・金の窓枠・ラウンジ・バー・植物・地球を見下ろすガラス床のある豪華なロビー。ステーションには当たり判定があり、ぶつかると船が壊れる。
- **小惑星は 3D で本当に飛んできて衝突**し、船体がへこむ・穴が開く・窓にひびが入る・配管が破れる・機器が壊れる。船内の壁も歪み、物が飛び、揺れる。
- 自分で直せるのは**ごく軽微な損傷だけ**。それ以外は放っておくと**どんどん悪化**し（ひびが広がって窓が割れる、漏れが増える、金属疲労で新しい損傷が生まれる）、船体強度が尽きると**船がバラバラに砕け散る**。大きな損傷は約10日かかる修理基地（ツクヨミ・ドック）でしか直らない。
- 船・ステーションが危険な状態になると**赤い非常灯が点灯し、警報がしばらく鳴る**（危険度に応じて船内照明も赤く染まる）。
- **ステーションと宇宙エレベーターにも小惑星が当たる**：焦げ跡・穴・空気の噴出・火災、照明のちらつき、居住リングの停止、クライマーの停止。大きく当たると崩壊して残骸だけになる（エレベーターはケーブルが切れる）。これはプレイヤーには直せない（生きている所はステーションの作業員が少しずつ直す）。ナビ画面に各施設の状態が出る。
- 区画ごとの気圧・酸素・二酸化炭素のシミュレーション。空気が漏れれば本当に減圧し、隔壁を閉じて閉じこもる必要もある。
- 床下の**配管層**は入り組んだ迷路。水再生装置・藻類バイオリアクター・姿勢制御ホイール・バッテリー群などが並ぶ。損傷箇所まで実際に行かないと修理できない。バルブで系統を遮断できる。
- 昇降機（リードスクリュー駆動）、コーヒーメーカー（グラインダー・ヒーター・ピストン）、シャワー、原子炉とタービン、サーバー、ファン、O2 生成装置、エアロックなど、**機械は内部機構ごと動作**する。
- **船外活動**：宇宙服を着て、エアロックを減圧し、ハッチから外へ。手すり・はしごあり。自由に船体の周りを飛べる。
- **大気圏突入**（加熱・プラズマ・振動）と**着陸・着水**（速度次第で損傷・破壊）。地球の重力下では船内にも重力がかかり、外を歩ける。
- **ULTRA**：最大秒速 900 m（従来の3倍）。点火時の衝撃や航行中の振動で、場合によっては船体が揺れたり壊れたりする（大気中や船体が弱っているほど危ない）。船体強度が60%を切るとアスファルトが安全のため ULTRA を止める（自己責任で再点火はできる）。解除すると段階的に元の速度へ戻る。ULTRA 中でも自動操縦が使える。慣性ダンパー付き。
- **自動操縦**はすべての目的地に到着できる（低軌道のステーション・宇宙エレベーターの途中駅・静止軌道・月軌道の修理基地まで）。
- **セーブしても世界は止まらない**：アプリを閉じていた時間も軌道上の移動・自動航行・損傷の悪化・衝突が進む（最大30日分）。
- 警報は派手（回転灯・赤い非常灯・画面の赤い脈動・サイレン）で、消音ボタンで止められる。
- **H8（エイチエイト）— カイトの昔のサブ拠点**：直径 7.2 m の球形の小型ステーション。この船より**外部装甲・内部装甲ともに倍以上分厚く**、面取りした装甲板（一枚ずつ色の違う板・交換された板・オレンジの赤道帯）を数千本のボルトで留め、外には専用カメラ4台・プラズマドライブ（磁気ノズル・超電導コイル・冷却管）・補助エンジン4基・RCS 8基・ラジエーター翼・レーダードーム・スタートラッカー・高利得アンテナ・レーザー端末・ドッキングネックと両性型ドッキングリング・高速給電カプラーがある。中は機械と配線がぎっしりで、真ん中のコックピットは**人ひとりがぎりぎり**。窓はなく、**4台のカメラ映像をリアルタイム合成した360度ディスプレイ**で外が見える（水平線・ピッチ目盛り・軌道マーカー・目標と距離・接近物の警告を AR 表示。電源を入れるとパネルが一枚ずつ起動する）。
  - H8 の AI「**HACHI**」は無口で頭の切れる自動操縦。地球を回り込む誘導・停泊軌道からの呼び出し・岩塊や他のステーションの回避・動いている B-29 への**精密自動ドッキング**までこなす。小さな岩は**レーザーで撃ち落とし**、大きな岩は回避機動をとる。
  - **B-29 の背中（上部ドッキングポート）に結合**できる。結合中は H8 が推進を担い、**内部原子炉だけで6倍、B-29 からの高速給電（アンビリカルケーブル）を受けると12倍**の速度が出る（ULTRA 時は最大 約 10.8 km/s）。B-29 のエンジンが壊れていても H8 の推力で飛べる。
  - 通路の天井の上部ポートから H8 に上がれる（ハッチは壁のパネルで開閉）。H8 の操縦席に座れば、そのまま結合した船を操縦できる。**分離して H8 だけで飛ぶ**こともできる（手動操縦・HACHI の自律航行・帰還ドッキング）。

## 遊び方

| 操作 | やり方 |
|---|---|
| 移動 | 画面の左側をドラッグ（仮想スティック） |
| 視点 | 画面の右側をドラッグ |
| 触る | 物を直接タップ（扉・座席・機械・バルブ・損傷箇所など） |
| モニター | タップすると近づく → ボタンをタップ。戻るときはモニターの外か左上のボタン |
| 上昇／下降 | 右端の ↑↓ ボタン（無重力のとき、はしご・手すりにつかまっているとき） |
| 立つ／戻る | 左上の退出ボタン |

### 操縦
- コックピットの操縦席をタップして座る。
- **左スティック**：上下＝速度（スロットル）、左右＝ヨー。**右スティック**：上下＝ピッチ、左右＝ロール。
- 左上のカメラボタンで**船外カメラ**。船外カメラを見ながらでもスティックで操縦できる。▶でカメラ切替。
- **ULTRA**：コンソール中央の赤いカバー付きスイッチ、またはナビモニターの ULTRA ボタン。
- **自動操縦**：ナビモニターで目的地をタップ →「自動操縦 開始」。修理基地に着いたら「ドッキング・修理」（H8 が結合していれば H8 の装甲も直る）。

### ステーションに寄る
1. ナビモニターで行き先のステーション（シラサギ、天の御柱など）を選び、自動操縦で近づく。
2. 近く（約 2 km 以内）まで来たら、ナビモニターの「**ドッキング**」をタップ。船がぐるっと回り込み、エアロック側から自動で接岸する（もう一度タップで中止）。
3. ドッキングしたら、エアロックの**外側ハッチ**を開ける（減圧は不要）。通路を抜けるとロビー。
4. 帰るときは船に戻って外側ハッチを閉め、ナビモニターの「**離脱（アンドック）**」。
- 天の御柱は軌道を回らず地球と一緒に回っているので、ドッキング中は船内にもロビーにも約 0.9G の重力がかかる。

### H8 を呼ぶ・乗る
1. ナビモニター左上の「**H8 を呼ぶ**」をタップ。停泊軌道で眠っていた H8 が起動し、HACHI が B-29 まで飛んできて背中にドッキングする（約10分。ナビの目的地「H8（サブ拠点）」を選んで自動操縦でこちらから迎えに行ってもいい）。
2. 結合したら、通路の天井（倉庫の扉の手前）にある**上部ポート**の下、壁の**青いボタン**をタップしてハッチを開ける。上に浮かんでいけば H8 のシャフト、その先がコックピット。
3. 操縦席をタップして座ると、B-29 と H8 をまとめて操縦できる（推力 6〜12 倍）。H8 のモニターで給電・ブーストの切替、カメラ映像、HACHI への指示ができる。
4. H8 のナビ画面「**分離して単独飛行**」で、カイトを乗せたまま H8 だけで飛べる。帰るときは「**B-29 へ帰還・ドッキング**」。乗っていないときに分離すると、HACHI が上で護衛するか停泊軌道へ帰る。

### 暮らし
- **コーヒー**：リビングのコーヒーメーカーをタップ。できあがったらもう一度タップして受け取り、画面右下をタップで飲む。無重力ではパウチに入る。
- **シャワー**：バスルームのシャワーをタップ（水は循環するが少しずつ減る）。
- **眠る**：リビングのモニター →「眠る（時間経過）」。寝ている間は時間が早く進む（警報中は眠れない）。
- **ラジオ**：5G の電波が届いていれば音楽が聴ける。

### 損傷と修理
1. 衝突するとアスファルトが音声でだいたいの場所を教えてくれる（システムモニターにもおおまかな位置が出る）。
2. 倉庫の**赤い修理キット**をタップして持つ。
3. 損傷箇所まで**実際に行って**、壊れている所をタップすると作業が始まる。
4. 小さな穴・ひび・小さな配管漏れ・軽い故障は応急処置できる。大きな損傷はツクヨミ・ドック（約10日）まで行かないと直らない。
5. 配管層へは、通路の昇降機（柵の黄色いボタン）か機関室の床中央のハッチ（はしご）から降りる。漏れている系統はバルブを閉めて止められる。
6. 減圧した区画は、穴を塞いでから生命維持モニターの「再加圧」で空気を戻せる。

### 船外活動
1. エアロック（右舷・通路の中ほど）に入り、ラックの**宇宙服**をタップして着る。
2. 内扉を閉め、エアロックのモニターで「**減圧**」→「**ハッチ 開**」。
3. 外へ。左スティックでジェットパック移動、↑↓で上下。手すりの近くでは体が止まる。船から離れすぎないように。
4. 戻ったらハッチを閉め、「**加圧**」してから内扉を開ける。
- 地上に着陸しているときは外の空気があるので、減圧せずにハッチを開けられる。

### パソコンで試す場合（キーボード）
WASD＝移動、矢印キー＝視点、Space / C＝上下、IJKL＝右スティック（操縦）、Q＝立つ、V＝船外カメラ、マウスクリック＝タップ。

## 動かし方

```bash
npm install
npm run dev      # http://localhost:5173 （同じ Wi-Fi のスマホからも開ける）
npm run build    # dist/ に本番ビルド
```

- スマホではホーム画面に追加すると全画面・横向きで起動します（PWA）。
- GitHub Pages で公開する場合は、リポジトリの Settings → Pages で Source を「GitHub Actions」にしてください。以降はプッシュのたびに自動で更新されます（すぐ反映したいときは Actions タブの「Deploy to GitHub Pages」→「Run workflow」）。
- 高性能なスマホ向けに、画質・アニメーションに妥協していません（WebGL2 必須）。

## 構成

```
src/
  core/      描画エンジン（多重視錐台レンダリング、自動露出、ポストエフェクト）、入力、音響
  world/     地球（四分木地形・大気・雲・高解像度タイル）、空、ステーションと 5G 基地局網、宇宙エレベーター、小惑星
  ship/      船体形状・外観・内装・部屋・配管層・扉・機械・飛行力学・自動操縦・生命維持・損傷・AI・セーブ・ゲームプレイ
  h8/        H8（球形の小型ステーション）：外装・内装・360度ディスプレイ・AI「HACHI」の操縦と自動ドッキング・B-29 の上部ポート
  player/    一人称プレイヤー（歩行・無重力・船外活動・はしご・水泳）、タップ判定
  ui/        船内モニター（キャンバス UI と船外カメラ映像）、HUD
tools/       素材生成スクリプト（NASA データ → テクスチャ）、ヘッドレス撮影テスト
```

- 恒星：HYG Database（CC BY-SA 4.0）
